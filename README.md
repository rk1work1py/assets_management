# assets_management — LINE家計簿・資産管理Bot

LINEに「ランチ 850」と送る、またはレシート写真を送るだけで家計簿がつき、
月1回の返信で株・預金などの資産推移も記録できる、**ランニングコスト0円**の個人向け管理システム。

## 構成

LINE Messaging API + Google Apps Script + Googleスプレッドシート + Gemini API(レシート解析)。
すべて無料枠内で動作し、口座連携は行わない(資産は月次の手動スナップショット方式)。

## 主な機能

- **支出登録**: テキスト(「ランチ 850」)またはレシート写真(Gemini解析→確認→登録)
- **振り返り**: 「今月」「先月」コマンドで即時集計。月初に先月レポートを自動配信
- **資産管理**: 月1回のリマインドに残高を返信してスナップショット登録、純資産推移を記録
- **データ所有**: 全データは自分のスプレッドシートにあり、直接編集・グラフ化・エクスポート可能
